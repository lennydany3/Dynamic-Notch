THE NOTCH, LIVE

It changes shape for whatever needs you.

01 / 06

Idle

A small black pill at the top edge. It stays clear of your taskbar, Alt-Tab and every window.

02 / 06

A notification arrives

The pill stretches, the app icon slides in and the message plays out inside the notch. Then it settles back.

03 / 06

Media playing

Album art, a live waveform and play/pause. Skip a track without finding the window.

04 / 06

Weather

Temperature and conditions from Open-Meteo, for a place you typed in yourself.

05 / 06

Your next event

A countdown to what's next, so a reminder never arrives as a surprise.

06 / 06

File Shelf

Drag a file up and the pill takes it. Drag it out again when you know where it goes.

FEATURES

What lives in the notch.

Each one opens from the same pill. Keep the ones you use and switch off the rest.

{{ il.notif }}

Notifications in the notch

Windows notifications land in the pill first, then file themselves away.

{{ il.media }}

Media controls

See what's playing, scrub and skip without finding the window.

{{ il.shelf }}

File Shelf

Drag a file up to the notch. Drop it somewhere else later.

{{ il.clip }}

Clipboard history

Memory-only, pauses while your password manager is focused.

{{ il.notes }}

Quick Notes

Type a thought before it's gone. No app to open first.

{{ il.shots }}

Screenshots

Recent shots slide into the notch as thumbnails.

{{ il.cal }}

Calendar & reminders

Your next event and a countdown, before the reminder interrupts you.

{{ il.sys }}

System monitor

Live CPU and RAM, read from the same counters as Task Manager.

{{ il.audio }}

Audio Quick Access

Switch speakers and mic from the top of the screen.

{{ il.bt }}

Bluetooth status

See what's connected at a glance.

{{ il.weather }}

Weather

Forecast from Open-Meteo for the town you typed in.

{{ il.auto }}

Launches with Windows
